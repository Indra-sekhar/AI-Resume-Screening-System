# 🤖 AI Resume Screening System

An AI-powered resume analysis system that automatically analyzes a candidate's resume and provides an ATS-style score, detected skills, resume sections, strengths, and improvement suggestions.

The system allows users to upload a resume PDF without entering a job description.

---

## 📌 Project Overview

Recruiters often receive hundreds of resumes for a single position. Manually reviewing every resume can be time-consuming.

This project aims to automate the initial resume screening process by extracting information from a resume and evaluating it using NLP and rule-based ATS techniques.
